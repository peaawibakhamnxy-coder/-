## 🛡️ ปรัชญาการทำงานตรงในเว็บ (100% In-App Direct Search)
- **ไม่เปิดเว็บอื่น / ไม่เปิดแท็บใหม่:** ผลลัพธ์ทั้งหมดถูกประมวลผลและแสดงผลตรงในการ์ดรายงานในหน้านี้ทันที
- **ไม่ใช้ QR Code:** ผู้ใช้พิมพ์เบอร์โทรศัพท์, เลขบัญชีธนาคาร หรือชื่อ-นามสกุลจริง แล้วกดค้นหาได้เลย
- **บอกข้อมูลครบถ้วนในหน้าเดียว:**
  1. ชื่อ-นามสกุลจริงของผู้ถือครอง
  2. เครือข่ายโทรคมนาคม (AIS, TrueMove H, DTAC, NT ฯลฯ)
  3. สถานะการเชื่อมต่อกับแพลตฟอร์มต่างๆ (LINE, Facebook, Instagram, TikTok, PromptPay, Truecaller/Whoscall)
  4. ประวัติการฉ้อโกง / แบล็กลิสต์คนโกง (Blacklistseller)
  5. ผลสแกนใบหน้าจับคู่ตัวตนและโปรไฟล์พร้อมเปอร์เซ็นต์ความแม่นยำ

## ⚡ 2 ระบบหลักในการใช้งาน (Dual In-App Engines)

### 1. 🚨 ระบบค้นหาเบอร์โทร / เลขบัญชี / ชื่อคนโกง
1. พิมพ์เบอร์โทรศัพท์ (เช่น `0812345678`), เลขบัญชี หรือชื่อ-นามสกุล
2. กดปุ่ม **"🔍 ค้นหาในเว็บนี้ทันที"**
3. ระบบจะแสดงการ์ดประวัติ (Dossier Report) ทันที:
   - **ชื่อจริง:** แสดงชื่อ-นามสกุลจริงที่ตรวจพบ
   - **เครือข่าย:** ระบุโอเปอเรเตอร์และพื้นที่
   - **การเชื่อมต่อแพลตฟอร์ม:** บอกสถานะบัญชี LINE, Facebook, IG, TikTok, พร้อมเพย์
   - **ประวัติฉ้อโกง:** ระบุว่าปลอดภัยหรือติด Blacklistseller พร้อมยอดความเสียหายและพฤติการณ์

### 2. 👤 ระบบค้นหาใบหน้าและระบุตัวตน (Face Recognition)
1. ลากรูปภาพใบหน้ามาวาง หรือกด `Ctrl+V` เพื่อวางภาพจากคลิปบอร์ด
2. ระบบตรวจจับตำแหน่งใบหน้า (Face Reticle) บน Canvas อัตโนมัติ
3. กดปุ่ม **"🔍 สแกนค้นหาใบหน้าในเว็บนี้ทันที"**
4. ระบบสแกนและดึงผลลัพธ์ตัวตนออกมาบอกในหน้านี้ทันที:
   - รูปเปรียบเทียบใบหน้า (ภาพที่อัปโหลด vs ภาพที่ตรวจพบ)
   - ชื่อและตัวตนที่ตรงกัน
   - ระดับความเหมือนของใบหน้า (Biometric Similarity % เช่น 99.4%)
   - รายชื่อบัญชีโซเชียลมีเดียที่ตรวจพบ
