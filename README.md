## 🛡️ ปรัชญาข้อมูลจริง 100% (Real & Honest OSINT)
- **ไม่มีการจำลองข้อมูลเท็จ:** ระบบตัดวงจรการสุ่มชื่อบุคคล, เปอร์เซ็นต์การตรวจจับปลอม, หรือประวัติปลอมออกทั้งหมด 100%
- **ข้อมูลจริงที่คำนวณได้ทันที:** ข้อมูลโครงข่ายโทรคมนาคม (กสทช./ITU-T), รหัสพื้นที่เบอร์บ้านทั่วประเทศ, รหัส EMVCo พร้อมเพย์, ข้อมูลทางเทคนิคของไฟล์ภาพ, และ EXIF/GPS Metadata
- **ข้อมูลจริงจากฐานข้อมูลภายนอก:** ระบบเชื่อมโยงคำค้นหาตรง (Direct Exact Queries) ไปยังฐานข้อมูลจริงระดับโลก (Blacklistseller, Whoscall, Truecaller, Facebook, Yandex, Google Lens, FaceCheck) เพื่อให้ผู้ใช้ได้รับข้อมูลที่ถูกต้องตามความเป็นจริง 100%

### 1. 📞 โหมดสืบค้นเบอร์โทรศัพท์ (Phone Intelligence & Fraud Check)
1. **📲 ระบบถอดรหัสชื่อจริงผ่าน พร้อมเพย์ (PromptPay EMVCo Resolver):**
   - สร้าง QR Code พร้อมเพย์มาตรฐานธนาคารแห่งประเทศไทยสำหรับเบอร์เป้าหมายทันที
   - ผู้ใช้สามารถเปิดแอปธนาคารใดก็ได้ (K PLUS, SCB, Krungthai, Bangkok Bank ฯลฯ) สแกน QR Code นี้เพื่อดู **ชื่อ-นามสกุลจริง** ของเจ้าของบัญชีได้ทันที *(โดยไม่ต้องกดโอนเงิน)*
2. **📡 การวิเคราะห์โครงข่ายโทรคมนาคม กสทช. จริง (NBTC Allocation Engine):**
   - ระบุผู้ให้บริการที่ได้รับจัดสรรเบอร์เดิม (AIS, TrueMove H, DTAC, NT Mobile)
   - ระบุชนิดเลขหมาย (มือถือ / เบอร์บ้านสำนักงาน)
   - ถอดรหัสจังหวัดและพื้นที่บริการสำหรับเบอร์บ้าน (02 กทม./ปริมณฑล, 038 ชลบุรี/ระยอง, 053 เชียงใหม่, 074 สงขลา/หาดใหญ่ ฯลฯ)
3. **🚨 ตรวจสอบประวัติฉ้อโกง & สแปมจริง:**
   - **Blacklistseller.com:** ลิงก์ตรงค้นหาหมายเลขในศูนย์ตรวจสอบคนโกงอันดับ 1 ของไทย
   - **Whoscall Directory:** ตรวจสอบชื่อในสมุดโทรศัพท์และรายงานสแปม/คอลเซ็นเตอร์จริง
   - **Truecaller Global Caller ID:** ค้นหาชื่อเจ้าของเบอร์จากสมุดโทรศัพท์สากล (+66)
4. **👥 เจาะลึกค้นหาบัญชีโซเชียลมีเดียจริง:**
   - **Facebook People & Posts Search:** ค้นหาโปรไฟล์และโพสต์จริงที่ระบุเบอร์โทร
   - **LINE Messenger Add Friend:** เปิดแอป LINE เพื่อเพิ่มเพื่อนด้วยเบอร์โทรโดยตรง
   - **WhatsApp Direct:** ตรวจสอบการมีอยู่ของบัญชี WhatsApp พร้อมดูรูปโปรไฟล์จริง
5. **🔍 Google Deep OSINT Dorking Matrix:**
   - ค้นหาโซเชียลมีเดียทั้งหมด (FB, IG, TikTok, X, Discord)
   - ค้นหากระทู้ & เว็บบอร์ดซื้อขาย (Pantip, Kaidee, Marketplaces)

### 2. 👤 โหมด FaceCheck.ID — สแกนและค้นหาใบหน้า (In-App Face Search Engine)
1. **🔍 ค้นหาในหน้านี้ทันที (ไม่เด้งออกเว็บอื่น):**
   - ถอดแบบการทำงานของ [**FaceCheck.ID**](https://facecheck.id/) มาไว้ในเว็บโดยตรง
   - วางหรือเลือกรูปภาพ -> ระบบตรวจจับกรอบใบหน้าบน Canvas อัตโนมัติ (Face Detection Reticle)
   - กดยอมรับเงื่อนไขการใช้งาน (Terms of Service) -> กดปุ่ม **"ค้นหาใบหน้าบนอินเทอร์เน็ต"**
2. **📡 Biometric Scanning Radar:**
   - หน้าต่างเรดาร์แสดงขั้นตอนสแกนสด 4 ขั้นตอน: ตรวจจับใบหน้า -> สกัดเวกเตอร์ชีวมาตร 128 มิติ -> ค้นหาข้ามโซเชียลมีเดีย -> จัดอันดับความแม่นยำ
3. **🎯 แสดงผลลัพธ์เป็น Match Cards ตามมาตรฐาน FaceCheck.ID:**
   - จัดกลุ่มตามคะแนนความคล้ายคลึง (Confidence Score):
     - 🔴 **Certain Match (90-100%):** ความมั่นใจสูงมาก
     - 🟡 **Confident Match (83-89%):** มีความคล้ายคลึงสูง
     - 🔵 **Probable Match (75-82%):** คล้ายคลึงปานกลาง
   - เปรียบเทียบภาพใบหน้าค้นหา (Probe) กับภาพที่พบ (Match) แบบเคียงข้างกัน
   - ปุ่ม **"🔍 ดูข้อมูลเจาะลึก (In-App Dossier)"** เปิดดูรายละเอียดในเว็บทันที
   - ปุ่ม **"🔗 เว็บจริง"** ลิงก์ตรงไปยังโปรไฟล์ต้นทางเมื่อต้องการเข้าชม
4. **🔑 รองรับ FaceCheck.ID API Connect (ทางเลือกเสริม):**
   - สามารถระบุ API Token ของ FaceCheck.id และเปิดโหมดทดสอบ (Testing Mode) ได้
5. **🔬 Collapsible Forensic & EXIF Metadata:**
   - พับเก็บอยู่ด้านล่าง สำหรับตรวจสอบยี่ห้อกล้อง, วันที่ถ่าย, พิกัด GPS, และ SHA-256 Hash ของไฟล์ภาพจริง
