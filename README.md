## ⚡ ฟีเจอร์ใหม่: ระบบ AI ค้นหาอัตโนมัติ (Autonomous AI Search & Matcher)

เมื่อเปิดไฟล์ **`index.html`** ในโฟลเดอร์นี้:
1. **ใส่รูปภาพเพียงรูปเดียว (ลากวาง หรือกด Ctrl+V วางภาพแคปหน้าจอ):**
   - ระบบ AI จะเริ่มทำงานและสแกนโดยอัตโนมัติทันที
   - มีเส้นเลเซอร์ไซเบอร์สแกนโครงสร้างภาพและใบหน้าแบบเรียลไทม์
2. **AI ตรวจค้นทุกแพลตฟอร์มขนานกัน:**
   - 🔍 **Google Lens & Web Index**
   - 📸 **Instagram (Meta)**
   - 💬 **Discord CDN & Servers**
   - 👥 **Facebook Media & Public Profiles**
3. **ประกบรูปภาพเปรียบเทียบแจ้งเตือน (Side-by-Side Visual Match Comparison):**
   - มีหน้าต่างแจ้งเตือนแบบ Popup เด้งขึ้นมาทันทีเมื่อตรวจพบภาพตรงกัน พร้อมเสียงเอฟเฟกต์ไซเบอร์ (Web Audio)
   - แสดงการ์ดประกบคู่เปรียบเทียบภาพ:
     - **ฝั่งซ้าย:** รูปที่คุณอัปโหลด (Target)
     - **ตรงกลาง:** ค่าความเหมือนของรูปภาพ (Match Confidence เช่น 98.4%)
     - **ฝั่งขวา:** รูปภาพที่ตรวจพบบนแพลตฟอร์มนั้นๆ
     - ลิงก์ตรงสำหรับกดเข้าไปดูโพสต์หรือโปรไฟล์ต้นทางทันที
4. **รองรับ Google Gemini AI Vision (ทางเลือก):**
   - มีปุ่มตั้งค่า Gemini API Key ด้านบน หากต้องการให้ Gemini AI วิเคราะห์เจาะลึกบุคคลและวัตถุเพิ่มเติม
